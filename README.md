# Curso – Aplicação Fullstack

## Descrição

Esta é uma aplicação **fullstack** desenvolvida para o gerenciamento de **alunos e cursos**, permitindo cadastrar, listar e remover informações de forma simples e organizada.

O projeto simula um cenário real de aplicação web, com **backend e frontend integrados**, seguindo boas práticas de separação de responsabilidades.

---

## Funcionalidades

- Cadastro de alunos  
- Listagem de alunos  
- Exclusão de alunos  
- Cadastro de cursos vinculados a alunos  
- Listagem de cursos por aluno  

---

## Backend

O backend é responsável por toda a **regra de negócio** e **persistência dos dados**, expondo uma **API REST** consumida pelo frontend.

Principais responsabilidades:
- Gerenciamento de alunos e cursos  
- Relacionamento entre entidades  
- Comunicação via JSON  

Tecnologias utilizadas:
- Java
- Spring Boot
- Spring Data JPA
- Maven
- Banco de dados H2 (ambiente de desenvolvimento)

---

## Frontend

O frontend é responsável pela **interface com o usuário**, consumindo a API REST do backend para exibição e manipulação dos dados.

A comunicação entre frontend e backend é feita via **requisições HTTP**.

---

## Arquitetura

- Aplicação fullstack
- Backend e frontend no mesmo repositório
- Comunicação baseada em API REST
- Separação clara de camadas (controller, service, repository)

---

## Objetivo do Projeto

Projeto desenvolvido com foco **educacional e demonstrativo**, aplicando conceitos fundamentais de desenvolvimento fullstack, integração entre sistemas e organização de código.
